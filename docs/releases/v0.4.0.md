# Quiet Line 0.4.0 · 文字曲线与 Mac 安装包

首个预编译 Mac 安装包，可直接下载后拖入「应用程序」，不需要安装 Swift 或 Xcode。

## 下载与安装

- 推荐：`Quiet-Line-0.4.0-macOS-universal.dmg`
- 备用：`Quiet-Line-0.4.0-macOS-universal.zip`
- 要求：macOS 14 或更新版本。
- 架构：Universal，包含 Apple Silicon（arm64）与 Intel（x86_64）。

打开 DMG，将 `Quiet Line.app` 拖到 `Applications`，再从「应用程序」打开。使用时选择标的、拖动曲线定位；双击隐藏，从菜单栏设置页恢复。

## 本次变化

- 新增「线条 / 文字曲线」切换：用正向文字组成真实价格走势，只在浮窗显示文字。
- 自定义短句循环、座右铭、天气示例文案与原创小说片段；支持导入本地 TXT，内容不上传。
- 支持 UTF-8、带 BOM 的 UTF-16、GB18030，单文件上限 5 MB。
- 可调滚动速度 0–100 px/s（0 暂停）、字号 9–24 pt；行情刷新或切换标的保留阅读位置。
- 设置预览与浮窗共用绘制逻辑，支持文本编辑的复制粘贴菜单。
- 提供 Universal `.app`、拖放安装 DMG 和 ZIP。
- 增加 Finder 应用图标、安装说明与 SHA-256 校验文件。
- README 增加预编译下载入口。
- 保留双击隐藏、设置页恢复，支持币安美股/ETF 映射永续与加密货币现货。

使用：设置页选择「文字曲线」，输入一句话或点「导入 TXT…」，然后调整速度和字号。天气文案为示例；文字滚动不代表出现新成交。修改文字或字号会从头开始。

## 签名状态

当前版本使用 ad-hoc 签名，尚未通过 Apple Developer ID 签名与公证。首次打开时 macOS 可能提示无法验证开发者。请核对下载来源与 `SHA256SUMS.txt`，如决定信任该版本，请按 [Apple 官方启动指引](https://support.apple.com/en-us/102445) 处理该应用的提示。

## 数据与兼容性

- 17 项离线测试通过；实际绘图组件完成文字滚动、暂停、双击隐藏和线条模式的离屏检查。
- DMG 只读挂载与 ZIP 解压校验通过；安装包内应用在 Apple Silicon 上成功读取 QQQUSDT、SPYUSDT、NVDAUSDT 的历史及最新成交。
- 目标行情请求周期为 2 秒，实际延迟取决于网络、交易和上游接口。
- QQQUSDT 等为币安永续价格，可能与美股现货或指数不同。
- 合约客户端默认尝试本机 `127.0.0.1:7897` 代理，然后在连接异常时尝试直连；其他端口见仓库开发说明。
- 两种架构均完成编译与签名校验；运行检查在 Apple Silicon 上执行，Intel 未进行实机测试。
