# Quiet Line 0.4.1 · 文字匀速与《青玉案》

- 新增贺铸《青玉案·凌波不过横塘路》全文预设，即“一川烟草，满城风絮，梅子黄时雨”那首词。
- 文字沿曲线匀速移动，陡处自动放慢横向速度，保留完整的价格曲线高低。
- 19 项离线测试通过，覆盖陡坡上的移动速度和完整峰值，以及已有行情与文字功能。

安装：下载 Universal DMG，将应用拖入 Applications，退出旧版后打开新版。支持 macOS 14+，包含 Apple Silicon 与 Intel；Intel 尚未实机测试。保留已有标的、文字、速度与外观设置。

本版本仍为 ad-hoc 签名，尚未经过 Apple Developer ID 签名及公证。首次打开如遇系统提示，请按 [Apple 官方指引](https://support.apple.com/en-us/102445) 处理。

词文参考：[古文岛《青玉案·凌波不过横塘路》](https://www.gushiwen.cn/shiwenv_9da2f1321a19.aspx)。
